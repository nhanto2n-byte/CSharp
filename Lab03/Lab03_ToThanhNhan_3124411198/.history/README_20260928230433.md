# LAB 03 - THỰC HÀNH LINQ CƠ BẢN
Te



## 1. Cấu trúc

- `BaiThucHanhLINQ/` - Console App C# dùng trong VS Code.
- `BaiThucHanhLINQ/Bai41.cs` - Bài 4.1 được tách riêng để dễ kiểm tra.
- `BaiThucHanhLINQ/Models/MonHoc.cs` - lớp MonHoc.
- `BaiThucHanhLINQ/Models/He.cs` - lớp He.
- `BaiThucHanhLINQ/Data/DuLieu.cs` - DS_Mon() và DS_He().
- `Lab03_LinqPad.linq` - file thử nghiệm trên LINQPad.
- `LinqPad_Notes.md` - ghi chú cách thử LINQPad.
- `BaoCao_Lab03.docx` - báo cáo có trang bìa và phần giải thích.

## 2. Chạy trên VS Code

Mở terminal tại thư mục `BaiThucHanhLINQ`:

```bash
dotnet restore
dotnet run
```

## 3. Bài 4.1

Bài 4.1 nằm ở `Bai41.cs` và gọi `DuLieu.DS_Mon()` để tạo/đọc `List<MonHoc>`. Kết quả in số lượng môn và toàn bộ danh sách môn học.

## 4. Trước khi nộp

- Điền mã sinh viên vào `BaoCao_Lab03.docx`.
- Chạy thử project trên máy.
- Nếu cần, chụp màn hình kết quả VS Code và LINQPad đưa vào báo cáo.
- Đổi tên file ZIP thành `Lab03_HoTen_MaSV.zip` theo yêu cầu giảng viên.
